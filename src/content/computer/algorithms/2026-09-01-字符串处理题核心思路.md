## LeetCode 13：罗马数字转整数

使用哈希表保存七种罗马数字的数值。遍历字符串时，如果当前字符的数值小于下一个字符，就执行减法；否则执行加法。最后将末尾字符的数值补入结果。

```python
class Solution:
    def romanToInt(self, s: str) -> int:
        ans = 0
        mapping = {
            "I": 1,
            "V": 5,
            "X": 10,
            "L": 50,
            "C": 100,
            "D": 500,
            "M": 1000,
        }
        for i in range(len(s) - 1):
            if mapping[s[i]] < mapping[s[i + 1]]:
                ans -= mapping[s[i]]
            else:
                ans += mapping[s[i]]
        return ans + mapping[s[-1]]
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。哈希表只有固定的 7 个字符。

关键点：比较相邻字符可以统一处理 `IV`、`IX`、`XL`、`CM` 等减法组合，不需要单独判断每一种特殊情况。

## LeetCode 14：最长公共前缀

先将字符串数组按字典序排序。排序后，所有字符串的最长公共前缀只需要在字典序最小的字符串和最大的字符串之间比较，因为中间字符串不会产生更短的公共前缀。

```python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        strs.sort()
        left, right = strs[0], strs[-1]
        i = 0
        while i < len(left) and i < len(right) and left[i] == right[i]:
            i += 1
        return left[:i]
```

复杂度：设有 `m` 个字符串，平均长度为 `n`。排序需要 `O(m log m)` 次比较，字符串比较还可能比较多个字符；排序后首尾比较为 `O(n)`。虽然 `sort()` 是就地排序，但 Python 的 Timsort 最坏情况下会使用 `O(m)` 的辅助空间。

关键点：该方法依赖字典序性质；输入数组为空时不能直接访问 `strs[0]`，需要根据题目约束决定是否增加空数组判断。

## LeetCode 20：有效的括号

使用哈希表保存右括号与对应左括号的关系，并使用栈保存尚未匹配的左括号。遍历字符串时，遇到右括号就检查栈顶是否为对应的左括号；遇到左括号则入栈。遍历结束后，只有栈为空才表示所有括号都完成匹配。

```python
class Solution:
    def isValid(self, s: str) -> bool:
        mapping = {")": "(", "]": "[", "}": "{"}
        stack = []
        for ch in s:
            if ch in mapping:
                if not stack or stack.pop() != mapping[ch]:
                    return False
            else:
                stack.append(ch)
        return not stack
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(n)`，其中 `n` 为字符串长度。

关键点：括号匹配具有“后进先出”的特点，因此栈是最合适的数据结构；遇到右括号时要先判断栈是否为空，避免对空栈执行 `pop()`。

## LeetCode 21：合并两个有序链表

### 迭代解法

使用一个虚拟头结点 `dummy` 简化链表头部的处理，再用 `cur` 指向当前合并结果的尾部。每次比较两个链表当前节点的值，将较小节点接到结果链表后面；循环结束后，将尚未处理的链表直接接到尾部。

```python
class Solution:
    def mergeTwoLists(
        self,
        list1: Optional[ListNode],
        list2: Optional[ListNode],
    ) -> Optional[ListNode]:
        dummy = cur = ListNode()
        while list1 and list2:
            if list1.val <= list2.val:
                cur.next = list1
                list1 = list1.next
            else:
                cur.next = list2
                list2 = list2.next
            cur = cur.next
        cur.next = list1 or list2
        return dummy.next
```

### 递归解法

递归时比较两个链表头结点，将较小的节点作为当前结果头部，再让它的 `next` 指向剩余链表的合并结果。遇到任意一个链表为空时，直接返回另一个链表。

```python
class Solution:
    def mergeTwoLists(
        self,
        list1: Optional[ListNode],
        list2: Optional[ListNode],
    ) -> Optional[ListNode]:
        if not list1:
            return list2
        if not list2:
            return list1
        if list1.val <= list2.val:
            list1.next = self.mergeTwoLists(list1.next, list2)
            return list1
        list2.next = self.mergeTwoLists(list1, list2.next)
        return list2
```

复杂度：两种解法都需要遍历两个链表，时间复杂度为 `O(m + n)`。迭代解法的额外空间复杂度为 `O(1)`；递归解法的调用栈空间复杂度为 `O(m + n)`。

关键点：算法直接复用输入链表节点，不需要创建新的数据节点；虚拟头结点可以统一处理第一个节点的插入逻辑。

## LeetCode 26：删除有序数组中的重复项

利用数组已经有序这一条件，使用双指针原地处理：`n` 指向当前不重复元素的最后位置，`i` 负责向后扫描。当 `nums[i]` 与 `nums[n]` 不同时，将它写入下一个不重复位置。最终前 `n + 1` 个元素就是去重后的结果。

```python
from typing import List


class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        n = 0
        for i in range(1, len(nums)):
            if nums[i] != nums[n]:
                n += 1
                nums[n] = nums[i]
        return n + 1
```

复杂度：时间复杂度为 `O(n)`，只遍历数组一次；空间复杂度为 `O(1)`，因为直接在原数组上覆盖写入，没有使用额外数组。

关键点：题目通常保证数组非空，因此上述代码可以直接返回 `n + 1`；若要兼容空数组，应先增加 `if not nums: return 0`。函数返回的是去重后有效元素的数量，数组后面的内容不需要关注。

## 今日复盘

- 哈希表适合把字符映射为固定数值，并在一次遍历中完成查找。
- 相邻元素比较可以把“特殊组合”统一为一个规则。
- 排序有时不仅用于排序，也可以帮助缩小后续比较范围。
- 嵌套结构的匹配通常可以使用栈，将“最近打开、最晚关闭”转化为后进先出。
- 合并有序链表时可以复用原节点，并用虚拟头结点消除头节点的特殊判断。
- 迭代和递归可以表达同一套合并逻辑，但空间复杂度和适用场景不同。
- 有序数组去重时，可以用读写双指针在原地完成压缩，避免额外空间。
- 需要区分“就地排序”与“辅助空间严格为 `O(1)`”：Python 的排序实现仍可能申请临时空间。
