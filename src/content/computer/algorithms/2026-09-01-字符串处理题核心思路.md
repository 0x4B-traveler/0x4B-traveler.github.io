# 相邻比较与字典序排序：字符串处理题的核心思路

今天的两道题都围绕字符串处理展开：第 13 题通过比较相邻字符判断加法或减法，第 14 题通过字典序排序将多个字符串的比较范围缩小到首尾两个字符串。

## LeetCode 13：罗马数字转整数

使用哈希表保存七种罗马数字的数值。遍历字符串时，如果当前字符的数值小于下一个字符，就执行减法；否则执行加法。最后将末尾字符的数值补入结果。

```python
class Solution:
    def romanToInt(self, s: str) -> int:
        ans = 0
        mapping = {
            "I": 1,
            "V": 5,
            "X": 10,
            "L": 50,
            "C": 100,
            "D": 500,
            "M": 1000,
        }
        for i in range(len(s) - 1):
            if mapping[s[i]] < mapping[s[i + 1]]:
                ans -= mapping[s[i]]
            else:
                ans += mapping[s[i]]
        return ans + mapping[s[-1]]
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。哈希表只有固定的 7 个字符。

关键点：比较相邻字符可以统一处理 `IV`、`IX`、`XL`、`CM` 等减法组合，不需要单独判断每一种特殊情况。

## LeetCode 14：最长公共前缀

先将字符串数组按字典序排序。排序后，所有字符串的最长公共前缀只需要在字典序最小的字符串和最大的字符串之间比较，因为中间字符串不会产生更短的公共前缀。

```python
from typing import List


class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        strs.sort()
        left, right = strs[0], strs[-1]
        i = 0
        while i < len(left) and i < len(right) and left[i] == right[i]:
            i += 1
        return left[:i]
```

复杂度：设有 `m` 个字符串，平均长度为 `n`。排序需要 `O(m log m)` 次比较，字符串比较还可能比较多个字符；排序后首尾比较为 `O(n)`。虽然 `sort()` 是就地排序，但 Python 的 Timsort 最坏情况下会使用 `O(m)` 的辅助空间。

关键点：该方法依赖字典序性质；输入数组为空时不能直接访问 `strs[0]`，需要根据题目约束决定是否增加空数组判断。

## 今日复盘

- 哈希表适合把字符映射为固定数值，并在一次遍历中完成查找。
- 相邻元素比较可以把“特殊组合”统一为一个规则。
- 排序有时不仅用于排序，也可以帮助缩小后续比较范围。
- 需要区分“就地排序”与“辅助空间严格为 `O(1)`”：Python 的排序实现仍可能申请临时空间。
