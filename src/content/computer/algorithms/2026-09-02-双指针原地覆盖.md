## LeetCode 27：移除元素

题目有两个目标：让 `nums` 的前 `k` 个位置保存所有不等于 `val` 的元素，并返回有效元素数量 `k`。

使用 `i` 作为读指针遍历数组，使用 `n` 作为写指针。当 `nums[i] != val` 时，将当前元素写入 `nums[n]`，再将写指针向后移动。

```python
from typing import List


class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        # 1. 使 nums 的前 k 个元素包含所有不等于 val 的元素
        # 2. 返回有效元素数量 k
        n = 0
        for i in range(len(nums)):
            if nums[i] != val:
                nums[n] = nums[i]
                n += 1
        return n
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。算法只遍历数组一次，并直接覆盖原数组，不需要额外数组。

关键点：函数返回后，只有 `nums[:n]` 属于有效结果，后面的元素无需处理。空数组会自然返回 `0`，不需要额外分支。

## 与第 26 题的联系

第 26 题“删除有序数组中的重复项”和第 27 题“移除元素”使用了相同的读写双指针框架：

- 读指针负责检查每个元素。
- 写指针指向下一个有效元素应写入的位置。
- 满足保留条件时执行覆盖并移动写指针。
- 最终写指针的值就是有效元素数量。

区别在于保留条件：第 26 题比较当前元素和最后一个有效元素，第 27 题判断当前元素是否不等于目标值。

## LeetCode 35：搜索插入位置

这是二分查找的边界变种。在有序数组中查找 `target`：如果找到就返回下标；如果没有找到，循环结束时左指针 `left` 正好位于第一个大于 `target` 的元素之前，也就是目标值应插入的位置。

```python
from typing import List


class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid
            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        return left
```

复杂度：时间复杂度为 `O(log n)`，空间复杂度为 `O(1)`。

关键点：每轮都必须排除 `mid`，因此右半区更新为 `left = mid + 1`，左半区更新为 `right = mid - 1`。原代码中的 `right = mid + 1` 会让搜索区间无法正确缩小。

循环结束时一定有 `left = right + 1`：`right` 左侧的元素都小于目标值，`left` 右侧的元素都大于目标值，因此 `left` 就是插入位置。这个结论也能自然覆盖插入数组开头、末尾以及空数组的情况。

## LeetCode 66：加一

从数组末尾开始向前遍历，因为末尾表示数字的最低位。如果当前位小于 `9`，直接加一并返回；如果当前位等于 `9`，将它置为 `0`，继续向前传播进位。只有所有位都是 `9` 时，循环才会完整结束，此时需要在最前面增加一个 `1`。

```python
from typing import List


class Solution:
    def plusOne(self, digits: List[int]) -> List[int]:
        for i in range(len(digits) - 1, -1, -1):
            if digits[i] < 9:
                digits[i] += 1
                return digits
            digits[i] = 0
        return [1] + digits
```

复杂度：最坏情况下需要遍历全部 `n` 位，时间复杂度为 `O(n)`。一般情况直接修改原数组，额外空间为 `O(1)`；当所有位都是 `9` 时，`[1] + digits` 会创建长度为 `n + 1` 的新列表，因此该实现最坏额外空间为 `O(n)`。如果不计算返回结果所占空间，通常也会将算法辅助空间记为 `O(1)`。

关键点：遇到第一位小于 `9` 的数字后，进位已经处理完毕，应立即返回；只有 `[9]`、`[9, 9]` 等全为 `9` 的输入才需要扩展数组长度。

## LeetCode 69：x 的平方根

题目要求返回非负整数 `x` 的算术平方根向下取整结果，可以把答案看作满足 `r² <= x` 的最大整数 `r`。

### 二分查找

在 `[0, x]` 区间内查找平方不大于 `x` 的最大整数。如果 `mid² < x`，答案位于 `mid` 或其右侧；如果 `mid² > x`，则继续搜索左侧。查找结束时，`right` 与 `left - 1` 都表示最后一个满足条件的整数。

```python
class Solution:
    def mySqrt(self, x: int) -> int:
        if x < 2:
            return x

        left, right = 0, x
        while left <= right:
            mid = left + (right - left) // 2
            square = mid * mid
            if square == x:
                return mid
            if square < x:
                left = mid + 1
            else:
                right = mid - 1
        return left - 1
```

复杂度：时间复杂度为 `O(log x)`，空间复杂度为 `O(1)`。

### 牛顿迭代法

牛顿迭代从一个估计值 `r` 出发，反复使用 `(r + x / r) / 2` 生成更接近平方根的新估计值。整数实现使用整除，并在 `r <= x // r` 时停止。

```python
class Solution:
    def mySqrt(self, x: int) -> int:
        if x < 2:
            return x

        r = x
        while r > x // r:
            r = (r + x // r) // 2
        return r
```

复杂度：牛顿迭代收敛很快，常用复杂度分析记为 `O(log x)` 时间、`O(1)` 空间；接近平方根后具有二次收敛特性，实际迭代次数通常少于普通二分查找。

关键点：`r > x // r` 与 `r * r > x` 含义相同，但除法形式在使用固定宽度整数的语言中可以避免乘法溢出。Python 整数不会溢出，不过这种写法更容易迁移到 C、C++ 和 Go。

## LeetCode 70：爬楼梯

到达第 `i` 阶只有两种来源：从第 `i - 1` 阶走一步，或从第 `i - 2` 阶走两步。因此状态转移为 `dp[i] = dp[i - 1] + dp[i - 2]`，与斐波那契数列相同。

### 动态规划数组

使用数组保存每一阶的方案数量。需要先处理 `n <= 2`，否则原写法在 `n = 1` 时访问 `dp[1]` 会越界。

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n

        dp = [0] * n
        dp[0] = 1
        dp[1] = 2
        for i in range(2, n):
            dp[i] = dp[i - 1] + dp[i - 2]
        return dp[n - 1]
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

### 滚动变量写法

当前状态只依赖前两个状态，因此不需要保存完整数组。使用两个变量滚动更新，可以把空间复杂度降到常数级。

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        left = right = 1
        for _ in range(2, n + 1):
            left, right = right, left + right
        return right
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。

关键点：状态定义和初始值必须对应。这里可以理解为 `left = f(0) = 1`、`right = f(1) = 1`；每次循环计算下一阶的方案数。Python 的多重赋值会先计算右侧，再同时更新两个变量，因此不会覆盖旧值。

## LeetCode 83：删除排序链表中的重复元素

链表已经按升序排列，因此重复节点一定相邻。遇到两个相邻节点值相同时，可以让当前节点直接指向下下个节点，从链表中跳过重复节点。

### 迭代解法

使用 `cur` 从头结点向后遍历。发现重复节点时只修改 `cur.next`，继续检查新的后继节点；只有当前节点与后继节点不相同时，才移动 `cur`。

```python
class Solution:
    def deleteDuplicates(
        self,
        head: Optional[ListNode],
    ) -> Optional[ListNode]:
        if not head:
            return head

        cur = head
        while cur.next:
            if cur.val == cur.next.val:
                cur.next = cur.next.next
            else:
                cur = cur.next
        return head
```

复杂度：时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。

### 递归解法

先递归完成后续链表的去重，再比较当前节点和去重后的后继节点。如果值相同，就返回后继节点；否则保留当前节点。

```python
class Solution:
    def deleteDuplicates(
        self,
        head: Optional[ListNode],
    ) -> Optional[ListNode]:
        if not head or not head.next:
            return head

        head.next = self.deleteDuplicates(head.next)
        return head.next if head.val == head.next.val else head
```

复杂度：时间复杂度为 `O(n)`；递归调用栈最深可能达到 `n` 层，因此空间复杂度为 `O(n)`。

关键点：迭代解法删除重复节点后不能立即移动 `cur`，因为新的 `cur.next` 仍可能与当前节点重复，例如 `1 → 1 → 1`。递归写法更简洁，但长链表可能受到 Python 递归深度限制。

## LeetCode 88：合并两个有序数组

`nums1` 的末尾已经预留了足够空间。使用三个指针从后向前遍历：`p1` 和 `p2` 分别指向两个数组当前未处理的最大元素，`p` 指向 `nums1` 当前应写入的位置。每次把较大的元素写到末尾，就不会覆盖 `nums1` 中尚未比较的有效元素。

```python
from typing import List


class Solution:
    def merge(
        self,
        nums1: List[int],
        m: int,
        nums2: List[int],
        n: int,
    ) -> None:
        # 双指针从后向前遍历，直接修改 nums1。
        p1, p2, p = m - 1, n - 1, m + n - 1

        while p1 >= 0 and p2 >= 0:
            if nums1[p1] > nums2[p2]:
                nums1[p] = nums1[p1]
                p1 -= 1
            else:
                nums1[p] = nums2[p2]
                p2 -= 1
            p -= 1

        while p2 >= 0:
            nums1[p] = nums2[p2]
            p2 -= 1
            p -= 1
```

复杂度：最多处理 `m + n` 个元素，时间复杂度为 `O(m + n)`；直接使用 `nums1` 的预留空间，额外空间复杂度为 `O(1)`。

关键点：如果 `nums2` 还有剩余元素，必须将它们复制到 `nums1` 前部；如果 `nums1` 还有剩余元素，则它们本来就在正确位置，不需要继续处理。从前向后合并会覆盖 `nums1` 中尚未读取的元素，因此本题应从后向前写入。

## LeetCode 94：二叉树的中序遍历

中序遍历的访问顺序是“左子树 → 根节点 → 右子树”。递归解法直接按照这个定义展开；迭代解法则使用显式栈保存暂时不能访问的祖先节点。

### 迭代解法

沿左子树不断下降，并把路径上的节点压入栈中。当无法继续向左时，弹出栈顶节点并记录其值，然后转向该节点的右子树。

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        stack = []
        result = []
        cur = root

        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left

            cur = stack.pop()
            result.append(cur.val)
            cur = cur.right

        return result
```

复杂度：每个节点入栈和出栈一次，时间复杂度为 `O(n)`；辅助栈最多保存树高 `h` 个节点，空间复杂度为 `O(h)`。如果把返回结果也计算在内，总空间为 `O(n)`。

### 递归解法

递归函数先遍历左子树，再记录当前节点，最后遍历右子树。

```python
class Solution:
    def inorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []

        def dfs(node: Optional[TreeNode]) -> None:
            if not node:
                return
            dfs(node.left)
            result.append(node.val)
            dfs(node.right)

        dfs(root)
        return result
```

复杂度：时间复杂度为 `O(n)`；递归调用栈空间为 `O(h)`，最坏情况下树退化成链表，此时为 `O(n)`。返回结果本身还需要 `O(n)` 空间。

关键点：迭代写法中的栈模拟了递归调用栈。原代码在空节点处使用 `return node` 也能结束递归，但返回值没有被使用，直接写 `return` 更清楚。对于极度不平衡的树，迭代写法可以避免 Python 的递归深度限制。

## LeetCode 101：对称二叉树

判断二叉树是否对称，本质上是比较根节点左右两棵子树是否互为镜像。镜像节点必须同时存在、值相等，并且左侧节点的左子树对应右侧节点的右子树，左侧节点的右子树对应右侧节点的左子树。

### 递归解法

递归函数每次接收一对应该互为镜像的节点，并按照“外侧对外侧、内侧对内侧”的顺序继续比较。

```python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True

        def check(
            left: Optional[TreeNode],
            right: Optional[TreeNode],
        ) -> bool:
            if not left and not right:
                return True
            if not left or not right:
                return False
            return (
                left.val == right.val
                and check(left.left, right.right)
                and check(left.right, right.left)
            )

        return check(root.left, root.right)
```

复杂度：每个节点最多访问一次，时间复杂度为 `O(n)`；递归调用栈深度与树高相关，空间复杂度为 `O(h)`，最坏为 `O(n)`。

### 迭代解法

使用队列保存等待比较的镜像节点对。每次同时取出两个节点，完成空节点和节点值检查后，再按照镜像顺序加入两对孩子节点。

```python
from collections import deque


class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        if not root:
            return True

        queue = deque([(root.left, root.right)])
        while queue:
            left, right = queue.popleft()
            if not left and not right:
                continue
            if not left or not right:
                return False
            if left.val != right.val:
                return False

            queue.append((left.left, right.right))
            queue.append((left.right, right.left))

        return True
```

复杂度：时间复杂度为 `O(n)`；队列中可能同时保存一层的大量节点对，空间复杂度为 `O(w)`，其中 `w` 是树的最大宽度，最坏情况下为 `O(n)`。

关键点：普通树遍历关注单个节点，而对称性检查必须成对处理节点。比较顺序不能写成左对左、右对右，而应是 `left.left` 对 `right.right`、`left.right` 对 `right.left`。增加空树判断后，代码也能安全处理 `root = None`。

## LeetCode 104：二叉树的最大深度

最大深度可以递归定义：空树的深度为 `0`；非空树的深度等于左右子树最大深度中的较大值再加 `1`。这个定义本身就可以直接翻译成递归代码。

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        # 空节点的深度为 0。
        if not root:
            return 0
        return 1 + max(
            self.maxDepth(root.left),
            self.maxDepth(root.right),
        )
```

复杂度：每个节点访问一次，时间复杂度为 `O(n)`；递归调用栈的深度等于树高 `h`，空间复杂度为 `O(h)`。平衡二叉树中 `h = O(log n)`，树退化成链表时最坏为 `O(n)`。

关键点：这里的 `1` 表示当前节点所在的一层。递归函数返回的是“以当前节点为根的子树深度”，因此左右子树的结果只需取最大值，而不是相加。

## LeetCode 110：平衡二叉树

平衡二叉树要求每个节点的左右子树高度差都不超过 `1`。使用后序遍历先计算左右子树高度，再判断当前节点是否平衡；如果发现任意子树不平衡，就返回 `-1` 作为哨兵并提前终止后续计算。

```python
class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def getHeight(node: Optional[TreeNode]) -> int:
            if not node:
                return 0

            left = getHeight(node.left)
            if left == -1:
                return -1

            right = getHeight(node.right)
            if right == -1:
                return -1

            if abs(left - right) > 1:
                return -1
            return 1 + max(left, right)

        return getHeight(root) != -1
```

复杂度：每个节点最多访问一次，时间复杂度为 `O(n)`；递归调用栈深度等于树高 `h`，空间复杂度为 `O(h)`，最坏情况下为 `O(n)`。

关键点：递归函数同时承担两个职责——正常情况下返回子树高度，发现不平衡时返回 `-1`。这样可以在一次后序遍历中同时完成高度计算和平衡性判断，避免对每个节点重复计算高度而退化到 `O(n²)`。

## LeetCode 118：杨辉三角

杨辉三角每行首尾都是 `1`，中间元素等于上一行相邻两个元素之和，即 `triangle[i][j] = triangle[i - 1][j - 1] + triangle[i - 1][j]`。

### 逐行构造

先创建一行全为 `1` 的列表，再根据上一行计算中间位置。

```python
from typing import List


class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        result = []
        for i in range(numRows):
            row = [1] * (i + 1)
            for j in range(1, i):
                row[j] = result[i - 1][j - 1] + result[i - 1][j]
            result.append(row)
        return result
```

### 预分配二维列表

先创建所有行及其正确长度，再从第三行开始填写中间元素。

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        result = [[1] * length for length in range(1, numRows + 1)]
        for i in range(2, numRows):
            for j in range(1, i):
                result[i][j] = result[i - 1][j - 1] + result[i - 1][j]
        return result
```

### `zip` 相邻求和

将上一行与去掉首元素后的上一行配对，直接计算所有相邻元素之和，再在首尾补上 `1`。

```python
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        result = [[1]]
        for _ in range(1, numRows):
            middle = [
                left + right
                for left, right in zip(result[-1], result[-1][1:])
            ]
            result.append([1] + middle + [1])
        return result[:numRows]
```

复杂度：三种方法都需要生成约 `n² / 2` 个元素，因此时间复杂度为 `O(n²)`，返回结果占用的空间复杂度也是 `O(n²)`。第三种写法还会为切片和当前行创建临时列表，但不会改变总体复杂度。

关键点：首尾元素不参与递推，只需要计算索引 `1` 到 `i - 1` 的中间区域。第三种写法使用 `result[:numRows]`，可以在 `numRows = 0` 时返回空列表；题目当前约束通常保证 `numRows >= 1`。

## 今日复盘

- 原地删除通常不是真的缩短底层数组，而是把有效元素压缩到数组前部。
- 当题目只要求返回有效区间长度时，不需要处理有效区间之外的内容。
- 识别读写双指针模板后，可以统一解决数组过滤、去重和原地压缩问题。
- 二分查找的关键不是记住代码，而是明确搜索区间的定义，并保证每轮都严格缩小区间。
- 查找失败时，左指针通常具有边界意义；本题中它表示目标值的插入位置。
- 模拟整数加法时应从最低位开始；提前返回可以避免处理不再受进位影响的高位。
- “原地修改”不代表所有执行路径都是 `O(1)` 空间，需要检查是否存在创建新列表的特殊分支。
- 同一个单调数值问题可以用二分查找保证稳定收敛，也可以利用数学性质设计更快的迭代公式。
- 在固定宽度整数语言中，应主动考虑 `mid * mid` 等运算的溢出风险。
- 动态规划应先明确状态含义、转移关系和初始条件，再考虑代码实现。
- 当当前状态只依赖有限个历史状态时，可以使用滚动变量压缩空间。
- 排序链表的重复元素必然相邻，可以通过修改 `next` 指针原地跳过节点。
- 递归代码通常更接近问题定义，但必须把调用栈计入空间复杂度，并考虑递归深度限制。
- 当目标数组末尾有预留空间时，从后向前合并可以避免覆盖尚未读取的有效数据。
- 双指针的遍历方向取决于覆盖风险：过滤和去重通常从前向后，原地合并通常从后向前。
- 树的递归遍历可以机械地转换为显式栈遍历，关键是保存尚未访问的祖先节点。
- 分析树算法空间复杂度时应使用树高 `h`，并区分辅助空间和返回结果占用的空间。
- 判断树的结构关系时，可以在队列或递归参数中成对保存需要比较的节点。
- 镜像比较的核心是交叉对应，而不是比较左右子树的相同方向。
- 树形动态问题可以先定义“递归函数返回什么”，再根据左右子树结果组合当前节点的答案。
- 树算法的递归空间由树高决定：平衡树通常是 `O(log n)`，退化树可能达到 `O(n)`。
- 后序遍历适合处理依赖左右子树结果的问题，父节点可以直接组合两个子树的返回值。
- 哨兵值可以同时传递计算失败或不满足条件的信息，从而支持递归提前终止。
- 二维动态规划可以按依赖关系逐行构造，先固定边界值，再计算内部状态。
- Python 的 `zip` 和列表推导式能简洁表达相邻元素运算，但仍要把切片和新列表计入空间分析。
