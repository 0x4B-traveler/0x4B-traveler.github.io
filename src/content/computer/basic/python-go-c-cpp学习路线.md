# Python → Go → C → C++：计算机基础融合学习路线

这是一份约 100 周、3.5～4 年的长期学习计划。路线采用“先建立工程能力，再逐步深入系统底层”的顺序：用 Python 快速建立编程和算法基础，用 Go 训练并发与网络服务，用 C 理解内存、系统调用和硬件，再用 C++ 完成高性能和分布式系统项目。

## 总体路线

| 阶段 | 周数 | 主要语言 | 同步基础 | 阶段成果 |
| --- | ---: | --- | --- | --- |
| 一 | 1–24 周 | Python | 数据结构、网络、数据库 | FastAPI 服务、异步爬虫、Python 库 |
| 二 | 25–48 周 | Go | 操作系统、网络编程、数据库实现 | 任务队列、RPC 框架、LSM 存储 |
| 三 | 49–64 周 | C | 组成原理、系统编程、内核 | HTTP 服务器、内存分配器、简易文件系统 |
| 四 | 65–100 周 | C++ | 高级数据结构、数据库内核、分布式系统 | 网络框架、Raft、分布式 KV/数据库 |

## 总目标与能力画像

完成这条路线后，不只是会使用四门语言，还应具备从需求、设计、实现到性能验证的完整系统开发能力：

- **工程开发能力**：能使用 Python 和 Go 快速构建稳定、可测试、可部署的服务。
- **算法与数据结构能力**：能根据问题选择合适的数据结构和算法，并说明复杂度与适用边界。
- **系统理解能力**：能从进程、内存、文件系统、网络协议一直追踪到 CPU、缓存和指令执行。
- **底层编程能力**：能使用 C/C++ 编写资源安全、并发正确、性能可测量的系统程序。
- **数据系统能力**：能实现从存储引擎、索引、事务到 SQL 执行的数据库核心组件。
- **分布式开发能力**：能实现基本的服务通信、日志复制、故障恢复和一致性机制。
- **技术表达能力**：能通过 README、测试、性能报告和技术文章解释设计取舍。

最终目标是完成一个简化的高性能分布式数据库，并能清楚回答：它如何存储数据、如何执行查询、如何处理并发、如何应对节点故障，以及瓶颈在哪里。

## 第一阶段：Python、数据结构与基础设施（1–24 周）

### 1–4 周：Python 基础与线性结构

- 学习 Python 语法、函数、模块、异常处理，以及列表、字典和集合。
- 用 Python 实现动态数组、链表、栈和队列，并补充复杂度分析与单元测试。
- 完成 20 道简单算法题。
- 项目：命令行文件批量重命名工具。
- 输出：博客《Python 数据模型与基础数据结构实现》。

### 5–8 周：面向对象、哈希表与网络入门

- 学习装饰器、生成器、迭代器、面向对象和函数式编程。
- 实现哈希表、递归算法和二叉树。
- 学习 TCP、Socket 和三次握手，并用 Wireshark 抓包分析。
- 项目：FastAPI TODO 服务，加入 JWT、SQLAlchemy 和 pytest。
- 输出：博客《装饰器原理与哈希表实现》。

### 9–12 周：异步编程与高级算法

- 学习 asyncio、协程和异步 I/O。
- 实现堆、优先队列、图、BFS、DFS、Dijkstra、常见排序和动态规划。
- 学习 UDP、IP 数据报和路由基础。
- 项目：基于 aiohttp、BeautifulSoup 和 MongoDB 的异步爬虫，并与多线程比较性能。
- 输出：博客《深入 asyncio 与图算法实现》。

### 13–16 周：元编程、性能与数据库

- 学习上下文管理器、描述符、元类和 Cython。
- 使用 cProfile 分析项目性能，并实现简单 ORM 或依赖注入容器。
- 学习 SQL、索引、视图、事务和数据库连接。
- 项目：Python C 扩展和基础数据库应用。
- 输出：博客《Python 元编程：从描述符到元类与 SQL 基础》。

### 17–24 周：开源与综合检验

- 学习 B+ 树、事务、锁和 Redis。
- 开发并发布一个 Python 库，测试覆盖率达到 80%。
- 向 FastAPI、Pydantic 等项目提交 PR。
- 复习数据结构、网络和数据库，完成若干困难算法题。

阶段验收（通过项目验证）：

- 批量重命名工具支持参数校验、错误处理和至少 3 个测试场景。
- FastAPI TODO 服务具备清晰的数据模型、JWT 鉴权、CRUD 接口和自动化测试。
- 异步爬虫能正确处理并发限制、超时和失败重试，并给出与多线程版本的性能对比。
- Python 库测试覆盖率达到 80%，能打包发布，并完成至少一次开源 PR。
- 能结合这些项目解释装饰器、元类、GIL，并说明何时选择同步、多线程、多进程或异步。

## 第二阶段：Go、操作系统与网络编程（25–48 周）

### 25–32 周：Go 基础、进程与网络服务

- 学习 Go 语法、接口、错误处理、goroutine 和 channel。
- 学习进程、线程、调度、内存管理和文件系统。
- 实现 FCFS、SJF、RR 调度模拟器和虚拟内存分页模拟器。
- 项目：HTTP 文件服务器、RESTful API 和 TCP 端口转发工具。

### 33–40 周：并发模式与运行时

- 学习 worker pool、pipeline、fan-in/fan-out、信号、管道和重定向。
- 学习 gRPC、负载均衡和系统调用。
- 阅读 Go GMP 调度模型及 `sync.Mutex` 源码。
- 项目：分布式任务队列、简易 Shell、高性能 HTTP 框架和 LSM Tree。

### 41–48 周：Go 综合项目

- 实现基础 SQL 解析器和事务机制。
- 开发自研 RPC 框架，支持服务注册、负载均衡和序列化。
- 实现 namespace、cgroups 相关的 Mini Linux 容器实验。
- 复习 TCP/IP、操作系统和并发安全。

阶段验收（通过项目验证）：

- HTTP 文件服务器支持优雅退出、请求取消、静态文件访问和基础错误处理。
- 任务队列支持 worker pool、任务失败重试和结果查询，并通过测试验证并发安全。
- RPC 框架至少具备序列化、超时、服务注册或负载均衡中的核心能力。
- LSM Tree 能完成 MemTable 写入、SSTable 持久化和基础查询，并提供基准测试。
- Mini Linux 容器能完成进程隔离或资源限制实验；能结合项目解释 goroutine、接口和 GMP 调度模型。

## 第三阶段：C、组成原理与系统底层（49–64 周）

### 49–56 周：C 基础、内存与缓存

- 学习指针、数组、结构体、函数指针、位运算和内存布局。
- 实现动态数组、链表、栈、队列和哈希表。
- 学习 CPU、ALU、汇编、内存对齐、大小端和缓存命中。
- 项目：`cat`、`wc`、8 位 CPU ALU 模拟器和简化版 `malloc/free`。

### 57–64 周：系统编程、网络协议与文件系统

- 学习 Socket、文件描述符、HTTP 请求解析和 xv6。
- 实现简易 HTTP 服务器、xv6 系统调用和简化版 ARP/IP 解析器。
- 学习 inode、目录和文件系统结构。
- 项目：简易文件系统和 B+ 树或 LSM Tree 存储引擎。
- 使用 Valgrind 检查内存泄漏。

阶段验收（通过项目验证）：

- `cat`、`wc` 和 HTTP 服务器能在正常输入、空输入和异常输入下稳定运行。
- 简化版 `malloc/free` 能完成基本分配与释放，并通过测试检查边界和重复释放问题。
- xv6 至少新增一个系统调用，并记录用户态到内核态的调用链路。
- 简易文件系统支持创建、读取、写入和删除文件，并能在重启或重新加载后验证数据。
- 主要 C 项目通过编译器警告检查和 Valgrind 检查；能结合代码解释指针、内存对齐、大小端和缓存。

## 第四阶段：C++、数据库内核与分布式系统（65–100 周）

### 65–76 周：现代 C++ 与高级数据结构

- 学习 RAII、智能指针、移动语义、STL、迭代器和模板。
- 实现 AVL 树、红黑树、B 树、图算法和简化版 `vector`。
- 学习虚函数表、对象布局、缓存优化、SIMD、原子操作和内存屏障。
- 项目：JSON 解析器、线程池和缓存友好的矩阵乘法。

### 77–88 周：并发、网络框架与数据库内核

- 学习模板元编程、CAS、内存序、Reactor 和 epoll。
- 实现无锁队列和 Reactor TCP 服务器。
- 实现数据库数据页、缓冲池、B+ 树索引、SQL 解析器、执行器、事务和 WAL。
- 输出：数据库内核设计文档和性能测试报告。

### 89–100 周：分布式系统与综合项目

- 学习 Raft 的 Leader 选举、日志复制、持久化和故障恢复。
- 实现基于 Raft 的分布式 KV 存储，并进行故障注入测试。
- 使用 perf 或 VTune 优化数据布局、分支预测和 SIMD。
- 最终项目：简化的高性能分布式数据库。

最终项目至少包含存储引擎、SQL 执行、网络通信、缓冲池、WAL、Raft 和基础事务支持。

阶段验收（通过综合项目验证）：

- 数据库能完成基础建表、插入、查询和更新，并有端到端测试。
- 存储引擎具备索引、持久化和恢复能力；WAL 测试能证明异常退出后数据可恢复。
- Raft 测试覆盖 Leader 选举、日志复制、节点重启和单节点故障。
- 网络框架具备并发连接处理、超时控制和基础性能基准。
- 性能报告至少包含吞吐量、延迟、资源占用、瓶颈定位和一次优化前后对比。
- 能解释虚继承、RTTI、异常机制、模板约束、内存序和无锁数据结构的设计取舍。

## 每周执行模板

- 语言学习：8–10 小时
- 计算机基础：6–8 小时
- 项目开发：6–8 小时
- 算法题：2–3 小时
- 总结输出：1–2 小时

每周完成 5 道算法题、一个可运行功能、一篇 300 字以上学习笔记、一次代码重构或测试补充，并整理一次 Git 提交。

每月完成一个项目里程碑、一篇技术文章、一次阶段复盘和一次知识点自测。

## 学习记录模板

每个知识点回答四个问题：

1. 它解决什么问题？
2. 核心原理是什么？
3. 如何用代码验证？
4. 它和其他知识点有什么联系？

每个项目至少保留 README、使用示例、单元测试、性能测试、技术难点和后续改进计划。

## 执行原则

1. 先保证项目能运行，再补充原理和源码阅读。
2. 时间不足时，优先保证项目开发，其次是计算机基础和算法题。
3. 每完成一个阶段，用检验清单自测；未达标时先补漏，再进入下一阶段。
4. 从第 1 周开始：阅读《Fluent Python》第一章，并实现一个带测试的动态数组。
